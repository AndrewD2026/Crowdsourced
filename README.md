# Crowdsourced Musical

A browser app for building a community-made musical. Users can:

- submit songs with lyrics, story placement, mood, key, tempo, and music notes
- add collaborative lyric lines and music ideas to existing songs
- select submissions from the shared pool and arrange a show order
- stitch the selected songs into generated musical scenes
- play the complete musical as a sequence of synthesized motifs

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
